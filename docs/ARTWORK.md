# Demo artwork and data

The fifteen films in the bundled `public/data/movies.json` are fictional examples written for this project. Their synopses, years, channel labels, editions, and example.org links are synthetic. They are not extracted records, recommendations, actual film availability claims, or downloadable film files.

All fifteen SVG posters under `public/posters/` and the landscape and favicon under `public/art/` were authored for this project from vector shapes, gradients, and text. No third-party photographs, film stills, studio posters, fonts, or stock assets were downloaded. These original project assets may be used, copied, modified, and distributed with this website. System fonts are used.

Do not interpret this statement as clearance for artwork or records in a Telegram archive. All actual imports remain private pending review. Imported posters require their own documented license and are decoded and re-encoded before publication. Archive SVGs, scripts, stylesheets, and HTML are never published by the importer.

The public artifact validator permits decorative artwork only through an explicit content-digest allowlist, and requires catalog poster assets to be referenced by cleared records. If original decorative artwork is intentionally edited, review it and update the allowlist in `scripts/validate_public.py`; rerun security tests and visual comparisons.
